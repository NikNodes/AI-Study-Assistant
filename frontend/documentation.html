Overview

AI Study Assistant is a full stack AI-powered web application that helps students upload notes, ask AI questions, generate quizzes, and manage study plans.

Main Modules

  • User Authentication
  • Notes Upload & Management
  • AI Chat Support
  • AI Quiz Generator
  • Study Planner

Technology Stack

  • Frontend — HTML, CSS, JavaScript
  • Backend — Node.js, Express
  • Database — MongoDB
  • AI — Groq API
